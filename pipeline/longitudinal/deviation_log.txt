0. RULES (decided 2026-11-02, C.S.)
--------------------------------------------------------------------------------
(v7) SUPERSEDED FOR THE LONGITUDINAL STUDY by section 15 (decided 2026-11-04).
Kept as history. The 5 mm threshold is ours, not published, and the run-agreement
check it relies on is unreliable on 27-slice data (section 15.7).
Registration, every later session:
  1. FEAT's standard registration (each run -> first-session T1, BBR) by default.
  2. If FEAT's runs disagree with each other by more than 5 mm, run step 07
     (each run -> first-session run-02 functional -> first-session FEAT transform).
  3. Keep step 07 only if its runs then agree within ~1 mm (validated range
     0.06-0.30 mm on 092/108). Otherwise keep FEAT and flag the session as a
     registration failure.
  Why 5 mm: FEAT's failures were 12-86 mm; every other session with a FEAT value
  was <= 2.2 mm (longitudinal_qc_compiled.csv, 39 sessions), so any threshold in
  that gap selects the same sessions. A 1 mm threshold would also catch sessions
  FEAT handled acceptably (sub-004 ses-02 1.5 mm, ses-03 2.2 mm; sub-018 ses-02
  1.1 mm, a first session, which has no step-07 fallback).
  First sessions have no fallback: a FEAT failure there is flagged.

2. WHY (as v3)
--------------------------------------------------------------------------------
FEAT's direct registration was inconsistent across runs of the same session
(run-to-run rmsdiff, after accounting for measured head movement between runs):
  sub-092 ses-02   13.8 - 85.8 mm
  sub-108 ses-02   20.2 - 38.6 mm
  good sessions    0.1 - 0.3 mm (sub-079 ses-02; ses-01 of 079/092/108: 0.15-0.33)
sub-092 run-01 vs run-02 head movement was under 0.5 deg / 0.3 mm, yet FEAT
placed run-01 about 60 deg and 68/89 mm away from runs 02 and 03.

Ruled out as causes:
  - pipeline setup: sub-diff (copy of sub-079) reproduced 079 exactly; 1stLevel
    .fsf identical between ses-01 and ses-02 apart from the anatomy path
  - anatomy FEAT used: reg/highres and highres_head identical (maxdiff 0)
  - scan protocol: JSON identical except converter version (sub-092 ses-02:
    dcm2niix v1.0.20260416 vs v1.0.20201102 elsewhere)
  - headers and voxel values: same structure, ordinary session-to-session range
  - head position between sessions: ses-02 vs ses-01 functional within ~2 deg,
    <8 mm; functional-to-functional correlation 0.98-0.99
  - T1 identity: ses-02 vs ses-01 T1 correlation 0.95-0.96 (079: 0.99)
  - timing: events match the .mat stimulus order, run matching, labels and the
    8.0 s start offset for both subjects; matches old timing files within 16 ms
  - (v4) slice count: of the three later FEAT failures, only sub-004 ses-05 is
    27-slice; sub-010 ses-03 is 69 x 2 mm in both sessions.
Cause of the FEAT failure: not identified [inferred: fragile direct
cross-session alignment].

Precedent:
  - SPM's multi-session realignment aligns each session's first scan to the
    first session's first scan, then coregisters once to anatomy (SPM manual).
    SPM "sessions" are usually runs within one visit.
  - (v4) Bonelli et al. 2012, Epilepsia (doi 10.1111/j.1528-1167.2012.03433.x),
    longitudinal fMRI before and ~4 months after anterior temporal lobe
    resection in adults: postoperative scans realigned, coregistered to the
    preoperative mean image, and normalized with the preoperative parameters.
    Closest published precedent found. Differences: Bonelli aligned one mean
    image per session; step 07 aligns each run's example_func. Adults, months
    apart, not developing brains across years.
  Citation choice for the methods: still to settle.

15. REGISTRATION RULE FOR LATER SESSIONS, LONGITUDINAL STUDY (2026-11-03/04)
--------------------------------------------------------------------------------
15.1 DECISION (C.S., 2026-11-04)
  Later sessions use the rule in 15.2, with one exception (15.3). The 5 mm rule of
  section 0 is retired for the longitudinal study.

15.2 THE RULE
  For every run of every later session, two registrations to the first-session T1:
   (a) FEAT: the run's standard FEAT registration (BBR). FEAT's original reg/ = the
       earliest reg.bak_*, or reg/ itself if none exists.
   (b) v2: FLIRT 6 dof, full search (+/-180 deg), run example_func -> first-session
       run-02 example_func (first available run if run-02 is missing); concatenated
       with the first session's FEAT example_func2highres.mat = starting estimate; then
       FLIRT BBR from that start (-cost bbr -dof 6, $FSLDIR/etc/flirtsch/bbr.sch,
       FEAT's highres_head and example_func2highres_fast_wmseg).
  Both are scored with FEAT's BBR cost (flirt -cost bbr, measurecost1.sch, same
  highres_head and wmseg; lower = better). Use v2 only if its cost is lower than FEAT's
  by more than 0.01; otherwise keep FEAT.
  Cutoff: across all 98 runs every |v2 - FEAT| is <= 0.003 or >= 0.066 (15.7), so any
  cutoff in that range assigns the same runs [verified: log].

15.3 EXCEPTION: sub-010 ses-03 KEEPS FEAT (C.S., 2026-11-04)
  By the rule all three runs would take v2 (v2 0.802-0.818, FEAT 0.884-0.930, gain
  0.066-0.128). Kept with FEAT because its FEAT fit was borderline rather than at the
  random level (~1.0), and FEAT's placement looked acceptable at thumbnail size (15.10).
  For the record: sub-092 run-01's FEAT cost (0.938) is within 0.008 of sub-010 run-02's
  (0.930), so the exception cannot be stated as a cost cutoff. It is a subject-level
  decision and is reported as one, with sub-010's v2 result shown alongside.

15.4 RATIONALE AND CITATIONS (checked against full texts, 2026-11-03/04)
  - Greve & Fischl 2009, NeuroImage 48:63-72. BBR converges only from a start in a
    narrow capture range (Conclusions: about +/-5 mm and 5 deg; initialization stage:
    roughly within 7 mm and 7 deg). The start may come from several methods
    (same-session geometry; a global intensity method such as FLIRT; a same-session
    whole-brain intermediate image; manual). In its perturbation test every start
    offset by < 5 mm/5 deg returned to the same solution. Failures are detectable from
    the cost (~1.0 away from the optimum), with the cutoff taken from representative
    data. Visual inspection recommended.
    Not covered: a cross-session intermediate image (its intermediate option is
    same-session); its figures describe FreeSurfer's implementation.
  - FSL wiki, FLIRT_BBR: FSL's BBR is a separate implementation in FLIRT, the default in
    FEAT; cite Greve & Fischl.
  - Bonelli et al. 2012, Epilepsia 53(4):639-650, doi 10.1111/j.1528-1167.2012.03433.x.
    44 patients, language fMRI before and ~4 months after anterior temporal lobe
    resection; SPM5; post-op scans realigned, coregistered to the pre-op mean image,
    normalized with the pre-op parameters; 4 patients excluded for coregistration
    problems. Not covered: applied to all post-op scans (not a subset); adults (median
    ages 35-37); no T1 or BBR step described.
  - Liu et al. 2025, Commun Biol 8:1200: all functional runs of each longitudinal
    patient co-registered to the first-session T1 with boundary-based registration.
    Silent on the starting estimate.
  - fMRIPrep documentation (1.0.8/1.1.4 workflow source; 25.1.0 usage): by default each
    BBR result is compared with its starting registration and rejected if it deviates
    excessively; forcing BBR skips that check. The fMRIPrep paper itself not checked.
  - Dropped: FreeSurfer bbregister docs (accurate but redundant).

15.11 DRAFT METHODS TEXT (for Marlene; not final)
  Later-session runs were registered to the first-session T1 with boundary-based
  registration (BBR; Greve & Fischl, 2009), as in Liu et al. (2025). Because BBR
  converges only from a starting estimate near the solution, each run was registered
  from two starting estimates: FEAT's default, and a rigid alignment to the first
  session's functional reference combined with that session's registration (cf.
  Bonelli et al., 2012). The result with the lower BBR cost was retained; where costs
  differed by less than 0.01, FEAT's registration was kept.
  Exception sentence (wording to agree): one session (sub-010 ses-03), whose FEAT cost
  was intermediate, retained FEAT's registration; results with the alternative
  registration are reported alongside.
